# Open-source TTS replacements for ElevenLabs — deep-dive (6 Oct 2026)

Method: live GitHub API stats (stars / last push / licence SPDX) pulled today; READMEs, LICENSE files and HF model cards read directly; leaderboards from the HF Open TTS Leaderboard (30 Sep 2026) and Artificial Analysis open-weights board; prices from provider pages. Where I could not verify, I say so (section 3).

## Headline findings

1. **No open model fully fits all six requirements.** The blocker is requirement 2+3 together: twelve stable *British* stock voices. Only Kokoro-82M and Kyutai pocket-tts ship British stock voices, and neither does voice design; every strong 2026 Chinese model (Qwen3-TTS, VoxCPM2, dots.tts, MOSS-TTS, GLM-TTS, CosyVoice3, IndexTTS2.5, Step-Audio-EditX) is clone-first with zero or only American-English presets.
2. **Several "open" leaders are not commercially usable.** Fish Audio S2-Pro (Fish Audio Research License), Breeze TTS 2 (#1 open-weights Elo, non-commercial weights), OmniVoice (14k stars; README says Apache but the *weights are CC-BY-NC* — maintainer confirmed 3 weeks ago), Higgs TTS 3 (Boson Research and Non-Commercial), Mistral Voxtral TTS (CC-BY-NC weights), F5-TTS, MaskGCT (NC weights), XTTS-v2 (CPML), ChatTTS (AGPL code + NC weights). KittenTTS 2's weights are under a "Stellon Labs Community License" (free under $1M revenue), not Apache as the repo badge suggests.
3. **Cloning from a synthetic reference is the realistic route to 12 British voices**, and both Apache-2.0 "design + clone" families (Qwen3-TTS and VoxCPM2) officially support that workflow. Apache-2.0 imposes no usage restriction, so a voice designed from text, saved as a WAV and then cloned is clean of third-party likeness rights. Caveat: British accent from a text description is "the only accent that works, inconsistently" (VoxCPM issue #285) and "unreliable" (Qwen3-TTS community guide); regional British (Scottish/Scouse/Brummie/Yorkshire/Welsh) and Nigerian are essentially unsupported by every model via text.
4. **For regional British accents the only legally clean stock options are VCTK-derived voices**: pocket-tts ships a Scottish (Edinburgh) female, a Manchester female, a Nottingham male, a Surrey male and two Southern-England females under CC-BY-4.0; Piper has `alba` (Scottish), `northern_english_male`, `southern_english_female` (MIT, dated quality).

## 2. Shortlist and recommendation

**Shortlist**

1. **Kokoro-82M** — the only Apache-2.0 model that satisfies "12 stable voices, British English, commercially safe, CPU-cheap, top English intelligibility" today. It has exactly 4 British female + 4 British male stock voices (bf_emma is the best-graded, B-), so you would fill the other four coaches with American voices or accept 8 British + 4 US. Limits: no voice design, no cloning, RP-only (no Scottish/Scouse/etc.), 2025 prosody (flatter than ElevenLabs), last commit Aug 2025. Cost at 3M chars/month: DeepInfra ~$1.90/month, or a $5 CPU box.

2. **Qwen3-TTS 1.7B (VoiceDesign → Base clone)** — the strongest 2026 Chinese option for your use. Workflow: write 12 persona descriptions ("woman in her 50s, warm, measured, slight British accent…"), generate 10–15 s with VoiceDesign, pick the takes that actually came out British, save them as reference WAVs, then serve everything through Base `create_voice_clone_prompt` so the voices are pinned. Apache-2.0 end to end, no third-party likeness. Streaming 97 ms TTFB. Expect to re-roll for accent; regional British will not come out. Hosted: Alibaba Model Studio ($10/1M) does not expose cloning of your own designed voice on the same terms, so you'd self-host (Baseten estimates $3–5/1M at scale) or use DeepInfra ($20/1M → ~$60/month at your volume) if they expose Base cloning.

3. **VoxCPM2** — best English SIM and naturalness MOS of the open models, 48 kHz, Apache-2.0, very active (38k stars, pushed last week), and the same design-then-clone trick works. Downsides vs Qwen3-TTS for you: needs ~8 GB VRAM and is slower than real-time on CPU; no major host serves it; accent by description is admitted to be unreliable (issue #285).

**Single best recommendation for "free/open, commercially safe, 12 stable voices, British English":** *none fully fits.* The closest honest answer is a **two-tier setup**: launch on **Kokoro-82M** (8 real British stock voices, Apache-2.0, pennies per month, no legal ambiguity), and in parallel build the **Qwen3-TTS VoiceDesign → Base-clone** pipeline to upgrade the four non-British coaches and later all twelve to more expressive 2026-quality voices. If you want regional accents (Scottish, Mancunian, Nottingham) *now*, Kyutai pocket-tts's VCTK voices (eponine, fantine, paul, charles, anna, vera — CC-BY-4.0, attribution to VCTK) are the only commercially clean source, but at 100M params it is a step down in naturalness and you must avoid its two CC-BY-NC voices. Nigerian English: no mainstream model; only niche fine-tunes (YarnGPT, SpeechT5 Nigerian) exist.

On the licence question for synthetic-source cloning: Apache-2.0 (Qwen3-TTS, VoxCPM2, MOSS, dots.tts, CosyVoice3) contains no field-of-use or voice-consent clause, so cloning from a voice you generated yourself is permitted; the "no impersonation/fraud" lines in their READMEs are disclaimers, not licence terms. Avoid using a *real* person's audio as the seed. Do not use this trick with IndexTTS (bilibili licence has prohibited-use list), Fish, Breeze, OmniVoice, Higgs 3 or Voxtral.

## 3. What I could not verify

- Replicate per-run price for `qwen/qwen3-tts` (page did not expose it); fal.ai/Replicate pricing for VoxCPM2 (not listed; "$5.80/1M" is from a third-party blog).
- Exact numeric scores on the HF Open TTS Leaderboard (blog shows screenshots only); TTS Arena V2 current table (JS-only).
- Whether the open Fun-CosyVoice3 can take an English-accent instruction (README shows only Chinese dialect strings); maintainers have not answered licence issue #1945.
- British-accent success rate for Qwen3-TTS, VoxCPM2, Maya1, MOSS-VoiceGenerator — only anecdotal reports; nobody has published a regional-British test.
- Genders of pocket-tts's non-VCTK voices (alba, caro_davy, javert, marius); VibeVoice-Realtime's full preset list beyond the 7 files in `demo/voices/streaming_model`.
- Zonos2 licence (repo MIT vs Zyphra tweet "Apache 2.0"), VRAM and RTF; Tencent AuK LICENSE file text (README says MIT, GitHub API shows NOASSERTION).
- GLM-TTS parameter count; Supertonic-3's per-voice accents.
